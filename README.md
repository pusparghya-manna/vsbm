Mobile Volume Shader is an interactive WebGL-powered 3D fractal visualization designed for smooth performance on mobile devices. It renders a complex mathematical fractal directly in the browser using GPU-accelerated shaders, with optimized ray-marching and surface detection for better performance. Users can freely rotate the fractal with touch or mouse controls and zoom using pinch or scroll gestures. The experience combines mathematical geometry, dynamic psychedelic coloring, lighting, reflections, and real-time animation into a lightweight, fullscreen 3D visualization.
